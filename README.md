# Clearpools

Clearpools is a conditional liquidity fork of Whirlpools, an open-source concentrated liquidity AMM contract on the Solana blockchain.
This repository contains the Rust smart contract and SDKs to interact with a deployed program.

The official deployment of the Clearpools contract can be found at the `C1ear1po7kcLBZiiArGMXPhGnjRZ8KxkqQ8EEskzHWmc` address on:
- [Solana Mainnet](https://solscan.io/account/C1ear1po7kcLBZiiArGMXPhGnjRZ8KxkqQ8EEskzHWmc)
